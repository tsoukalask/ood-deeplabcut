# VNC Connect

## Repository
[GitHub Release](https://github.com/tsoukalask/ood-deeplabcut)

A VNC Connect app designed for Open OnDemand that launches Deeplabcut with GUI as a job.

## Prerequisites

A conda environment. You should provide a conda environment that will be used to create virtual environment DEEPLABCUT and install the gui version.

## Install

1. Activate a conda environment
2. Make sure create_venv.sh is executable
3. Run the create_venv.sh
4. Edit the template/script.sh.erb to correct the path to the conda environment
5. Edit the manifest to update information
